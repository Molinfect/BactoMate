BactoMate — source archive
============================

This folder is a GitHub "Source code" archive of the BactoMate repository.

Lab users
---------
Download BactoMate.dmg (macOS) or BactoMate-win64.zip (Windows) from:
  https://github.com/Molinfect/BactoMate/releases/latest

Install from those release files. Do not run the setup installers in this folder unless you intend a developer source install.

Developers (source install)
---------------------------
Use plain Python 3.11 (system or python.org installer; avoid Conda and Python 3.12 or newer).

  macOS:   ./setup/macos/install.sh
  Windows: setup\windows\install.bat

Full steps: setup/README.md
