Folder tree (canonical)

MyExperiment/ ← sample root ├── raw_movie.nd2 ├── Tif_files/ ← File Conversion (fixed name) │ ├── 2_Phase60x.tif │ ├── 2_fi_GFP.tif │ ├── 2_foci_GFP.tif │ └── _segmentation_bact_phase_omni/ ← Segmentation (model slug) │ ├── 2_Phase60x_masks.tif │ ├── 2_Phase60x_cellids.tif │ ├── 2_Phase60x_overlay.tif (+ .png) │ ├── foci_detection/ │ │ └── 2_foci_GFP.csv │ ├── foci_filtered/ ← after Filtering │ │ └── 2_foci_GFP_filtered.csv │ └── filtered_masks/ │ └── 2_Phase60x_mask_filtered.tif ├── _analysis/ ← Analyze (sibling of Tif_files) │ ├── 2_Phase60x_analysis.xlsx │ ├── 2_Phase60x_filter_visualization.tif (+ .png) │ ├── 2_Phase60x_analysis_visualization.tif (+ .png) │ └── MyExperiment_combined_summary.xlsx └── _tracking/ └── 2_Phase60x_masks_tracking/ ├── *_tracks.csv · *_report.xlsx ├── *_masks_tracked.tif · *_overlay_tracked.tif └── tables/

Key rules

  • _analysis/ and _tracking/ live at the sample root (parent of Tif_files/).
  • _segmentation_* usually lives inside Tif_files/, not at sample root.
  • Filtering writes into filtered_masks/ and foci_filtered/ under the same segmentation folder.
  • Standalone TIFF input (not in Tif_files/) uses {stem}_omnipose_segmentation/ instead — same inner layout, different parent path.
