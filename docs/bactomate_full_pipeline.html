Module reference (detailed)

0 · Workspace

  • Dashboard with module cards
  • bactomate_project.json stores paths and UI state
  • Workspace scan suggests inputs per module
  • Session logs JSON: replay parameters across sessions
  • Interactive preview in File conversion (LUT, T/Z/C)

1 · File conversion

  • ND2, LIF, CZI, TIFF → Tif_files/
  • Separate channels, custom names in filenames
  • Drift (X/Y) and photobleaching correction
  • Crop ROI, Z max projection, frame limits
  • Manual metadata override (µm/px, min/frame)

2 · Segmentation

  • Omnipose, Cellpose-SAM, or U-Net inference
  • Batch folder processing with file picker
  • Persistent Cell IDs always after segment
  • Overlay with Cell ID labels (TIFF + PNG)
  • Spotiflow foci detection → CSV + overlay per channel
  • Embedded Filtering and Analyze stages below

3 · Filtering

  • Live preview with accept/reject overlay
  • Size and rod-shape morphology filters
  • Border exclusion
  • Foci CSV peak filtering (prob, intensity, area)
  • Writes filtered_masks/ and foci_filtered/
  • Filter QC visualization in _analysis/

4 · Analyze

  • Per-cell morphology and area time series
  • FI: mean, contour, interior, CV, top-10% stats
  • Foci: global ID, cell_id link, spatial T1–T3 metrics
  • Colocalization between FI/foci channel pairs
  • Excel: Summary, Per-Cell, Foci, Run Info sheets
  • Combined summary (long + wide + stacked foci)
  • Multi-panel analysis visualization TIFF + PNG

5 · Tracking

  • Trackastra greedy / ILP / no-div modes
  • Preview (in-memory, no disk write)
  • Movement tracking + lineage with divisions
  • Track QC filters (gaps, length, displacement)
  • Merge with analysis Cell_ID and per-cell stats
  • Lineage curation UI + family-tree analysis
  • CTC export, parquet tables, report workbook

6 · Post-processing

  • Multi-image montage with labels and scale bar
  • Per-tile contrast, color, Z projection
  • Scale bar on a single image
  • Growth-curve video: movie + graph side-by-side
  • FI channel overlays in growth-curve video

7 · Training

  • Shared image + mask dataset folder
  • Pair validation and overlay preview
  • Dataset augmentation tools
  • Omnipose / Cellpose-SAM / U-Net training panels
  • Models feed back into Segmentation module

CLI / batch

  • python main.py GUI launcher
  • convert_nd2_to_tif
  • batch_process_tiff_sequence
  • analyze_cell_areas
  • batch_process_folder end-to-end

Typical end-to-end path

Open workspace → Convert raw files → Segment phase stacks → Filter cells and foci → Analyze (FI + foci + Excel) → Track (optional lineage) → Post-process figures/video. Training runs independently when you need a custom segmentation model.
